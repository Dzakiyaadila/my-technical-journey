# My Tech Journey

Welcome to my little corner of the internet where I document my journey through technology.

This repository is not meant to be a collection of polished tutorials or fancy explanations about *"What is Docker?"*, *"How does Git work?"*, or *"Introduction to Machine Learning."*

There are already plenty of great resources that explain those things far better than I could.

Instead, this repository is about something more personal:

> **How I encounter technology, interact with it, build with it, struggle with it, make decisions around it, and slowly learn to understand it.**

I learn best by building things.

Sometimes that means starting a project without fully understanding what I am doing yet. Sometimes it means spending hours debugging an error that eventually teaches me more than a tutorial ever could. Sometimes it means making a technical decision, realizing later that it was not the best one, and understanding why.

This repository is where I document those moments.
